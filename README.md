# FORK

One Singapore neighbourhood. One generator. Six rounds. Two futures.

Choose between keeping a clinic powered and repairing a workshop's grid. A medic, engineer and courier respond. Rewind the starting checkpoint and compare both six-round outcomes: service, downtime, repairs and battery charge.

[Download packages](https://github.com/aGamingGod1234/fork-minecraft/releases) · [Install and play](tools/fork-release/README-INSTALL.md) · [Current execution plan](https://9z2w1doyakas.postplan.dev/)

Minecraft Java **26.1.2**, Fabric Loader **0.19.3** and Java **25** are required. The download includes FORK, Fabric API and Carpet. Optional verified downloads install Sodium, Iris and MakeUp Ultra Fast. A dedicated instance keeps existing worlds separate. Live mode needs your own supported Codex account/runtime; the separately labelled Fixture mode provides a deterministic local demonstration.

Press **G** for the console. Choose Clinic or Workshop, Advance to round six, Rewind, play the other branch, then Compare. Director runs the camera paths automatically.

The mapped world covers a **256 × 256 metre Market Street CBD district** at one block per metre. OpenStreetMap supplies geometry and available heights. Facade materials are reference-guided approximations, with missing details and edge clipping documented. The clinic/workshop is game scenery. The film's Singapore locator is a separate orientation map.

Build and automated game checks pass, including canonical A/B, three bounded restores and checked Visit/Return on the revised world. Current Laptop visual/live-film acceptance is still pending; preview releases are labelled accordingly. The matching 90-second gameplay film will be attached to the accepted release.
