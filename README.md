# FORK

A Minecraft Java game about two futures for one Singapore neighbourhood. Three inhabitants share one generator, two battery charges, and six rounds. Choose clinic or workshop power, inspect decisions, rewind the bounded starting checkpoint, and compare equal-length runs.

Build in progress during the 13 September 2026 hackathon, 10:30–15:30 SGT. This repository is private. A recipient-tested release and matching 90-second film are the delivery targets; no release is accepted yet.

Requires Minecraft Java 26.1.2, Java 25, Fabric Loader 0.19.3, Fabric API 0.150.0+26.1.2 and Carpet 26.1+v260402. Compatibility is version-specific. An existing legitimate Minecraft installation and separately authorized provider access are required for live mode.

Derived with the owner's authorization from Agent Arena commit `f220557a3a63a930d90e56734d7a97cdc38e0745`. Reused foundation includes inhabitants, lifecycle, console, provider transport and camera controls. FORK's power rules, bounded checkpoint restore and comparison are new hackathon work. See `coordination/reuse-ledger.md`.
