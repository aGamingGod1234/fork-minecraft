# Streaming writer verification

The writer spools validated JSONL runs to SQLite, retains one source chunk's runs and at most two transient NBT chunk trees, and computes spawn with a running minimum. Each region is written and reopened incrementally, with canonical typed-NBT hash checks before atomic publication. The completed world is promoted only after all regions and metadata pass. The default chunk limit remains explicit; increasing it does not increase the in-memory world size.

On 13 September 2026, an actual 256-metre regression regenerated the accepted 181,821-run district under an enforced one-CPU, one-process, 4 GiB Windows Job Object. Generation took **8.243 seconds**, with **56,295,424 bytes (53.7 MiB) peak process working set**. The largest chunk buffered 9,225 runs; 256 chunks were verified. The source world remained unchanged, and every output world file was byte-identical to the accepted candidate, including modern settings and spawn.

The accepted semantic digest therefore remains `99837940f5bd1d17e869284da89335b5955c83301cac0b04061d43782f590e78`, inherited through exact world-file identity. This is a district regression, not a whole-island performance claim. The proof is `queue/jobs/p256/attempt-2/proof.json`, SHA256 `252980878ADB1CA3CBC575C90BA069D4462ED26240E4334B23333B9C3CC27DC1`. Its process was PID 40692, created at `2026-09-13T09:15:39.8628050Z`, and is stopped. An earlier detached SSH attempt did not complete and is excluded from acceptance.

`tests/test_streaming_equivalence.py` independently compares frozen `04dacfb` against the streamed implementation using isolated four-chunk fixtures. It snapshots the baseline with `git show` and snapshots candidate dependencies, including `run_spool.py`. Negative coordinates, reversed input order, air windows, vegetation, water, terrain replacement, strict conflict rejection, repeated reopening, modern spawn, region layout and external settings all pass. Decoded semantic SHA256 is `3bfe65c1f22eb01a74465ee870d9f4f0443023f2c004f17df07f1eeedc174c8a`, with identical MCA and metadata bytes. Tiny-fixture memory is dominated by fixed interpreter/codec overhead and does not demonstrate a memory reduction.

The small harness exposed a Windows path-length failure. The final Anvil implementation uses native extended drive/UNC paths, shorter temporary names, and tested paths longer than 300 characters. World staging names are also short. No Windows policy change was made.

The final focused suite contains 92 passing tests. Further 1,024-metre dense, rural and coast benchmarks require coordinator leases and their own measured process-tree peaks. The existing successful Minecraft 26.1.2 district runtime remains applicable through exact world-byte identity; client appearance and AI behavior are separate gates.
