Your own Singapore.
At one block per metre.

Build the entire mapped Singapore territory as an explorable Minecraft world, with documented sources and measured geometric accuracy. This work continues beyond the hackathon; the current film and playable district remain separate.

In progress: four isolated workers own coordination, source data, generation and validation. The dated 250,727,913-byte OpenStreetMap extract and two Copernicus elevation tiles are downloaded and hashed. Two 128 by 128 metre SVY21 test tiles have generated successfully: 0.032768 square kilometres of unique core area. They remain separate test worlds. The fleet resumed after an execution interruption.

Build sequence

  1. Hash and catalogue whole-island roads, coastlines, buildings and available terrain. Retain licences and original data.
  2. Generate a small tile on one shared metre grid. The metre projection passes nine official reference points, but the shared boundary currently FAILS: 45,240 of 2,654,208 compared block cells differ. Fix this structural mismatch before scaling out.
  3. Process resumable 1,024-metre tiles with source overlap. Assemble neighbours only after boundary validation.
  4. Audit island coverage, fill documented gaps, and test a separate playable world before release.

Decisions and limits

Desktop owns this build. Generation currently uses one worker and reserves two CPU cores and 6 GB RAM for the current mod repair. The existing game, saves and capture remain untouched. Every output distinguishes mapped, estimated and missing geometry.

One block per metre does not imply photograph-exact buildings. OpenStreetMap has incomplete heights and facades; an initial flat ground plane is not measured terrain. Terrain, interiors, facade details and every individual object require additional suitable data and validation. No full-island completion date is claimed before measured tile throughput.

First acceptance gate

Source hashes, real generated test tiles and independent metre-coordinate checks pass. Next: one correctly joined strip, then measured dense-city, rural and coastline generation time, peak memory and disk size. No credible complete-world ETA or playable full-island world exists yet. Full-world acceptance also requires all mapped territory, suitable terrain, documented building detail and playable installation checks.
