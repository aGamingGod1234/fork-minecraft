This package covers a compact approximately 256 x 256 metre Singapore CBD
extract near Market, Cecil and Cross Streets, at one Minecraft block per metre.
It is not all Singapore. Buildings crossing the boundary are partial. The base
is flat because land-cover acquisition failed. Missing/conflicting OSM heights
and generator roof offsets remain; the scene is not a surveyed digital twin.

DATA AND MODIFICATION SOURCE OFFER
The accompanying world-sources directory contains the exact public OSM API
extract, acquisition record, filtered renderer input and exclusion record.
The original OSM data and derived geographic database are supplied under ODbL
1.0. The visual patch manifest lists every changed coordinate and before/after
material. The patch program and court JSON describe the added visual work.
Preserve this source directory and notice when redistributing the world.
Main must bundle the patch program and manifest alongside the final download.

ARCHITECTURAL REFERENCES
CapitaGreen: CapitaLand, 138 Market Street property page.
https://www.capitaland.com/sg/en/lease/commercial-space-listing/capitagreen.html
Reference features: glass facade, vertical planting, crimson roof crown.
Only the in-bounds facade receives approximate material accents. The cropped
crown is not reconstructed. No CapitaLand photograph is redistributed.

CapitaSpring: CapitaLand, 9 February 2022 completion release and Design Fact Sheet.
