Once Main supplies the accepted FORK profile and exact controls:

1. Keep one legitimate Minecraft client open on Laptop. In OBS select the prepared `FORK Readiness1080p30` profile, check the game picture and desktop audio meters, and record locally to the Cinematic `media/source` folder. Use MKV to protect an interrupted take. Do not show login, credentials or unrelated windows.
2. Record a 15-second game view with one spoken sentence. Stop and play it once. Confirm readable UI, smooth picture and audible speech. Cinematic checks the resulting file and handles trim/join/title/mix/export. This is the remaining real-input proof, not a request to edit.
3. Record one continuous take: INITIAL values; clinic allocation; all six committed A rounds; hold A result for at least 5 seconds; actual rewind and restored INITIAL values; workshop allocation; all six B rounds; hold B result for at least 5 seconds; show comparison motionless for at least 12 seconds; show one role's proposal, validation and effect. Keep the actual mode label visible. Never skip the waiting in the source recording. Cinematic trims waits in the edit.
4. In a separate take, record 5 seconds each of the two power routes, a court overview, entering the clinic and medic, engineer/repair indicator, and courier/spare. Only record visit/return or facade/restore if Main has accepted them. No new world edits or feature work for the film.
5. After Cinematic locks the outcome wording, read each numbered narration line as a separate take, leaving a quiet second before and after. Record the supplied alternatives too. Use the existing microphone/recorder or OBS; no music in the voice recording. Tell Cinematic the saved filename. Do not try to fit pauses by speeding up speech.
6. Watch the final 90-second file once, with sound. Confirm the comparison is readable, subtitles match the voice, and no account information appears. Main handles hosted viewing and publication.

If a take fails, leave the file intact and identify the problem. Stop camera playback before travel or rewind. Camera stop does not return the player. No capture on Desktop.
